# 🚲 따릉이 수요 예측모델 개발 및 시뮬레이션

기상 조건과 과거 대여량으로 **다음 날 서울 공공자전거(따릉이) 일별 대여건수**를 예측하는 LSTM 모델과,
날씨를 바꿔 가며 수요 변화를 확인하는 **Streamlit 시뮬레이터**입니다.

> 배포 주소: https://omndlprj.streamlit.app/

## 1. 한눈에 보기

| 항목   | 내용                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------- |
| 데이터 | 서울 열린데이터광장 공공자전거 일별 대여건수 + 기상청 서울 ASOS 일자료, 2024-01-01 ~ 2026-06-30 (912일) |
| 입력   | 직전 14일 시퀀스(대여량 + 기상·달력) + 예측 대상일의 기상·달력 변수                                     |
| 모델   | LSTM(64) → LSTM(32) + 대상일 Dense(16) → Dense(32) → 출력 1 (파라미터 33,921개)                         |
| 분할   | 시간 순서대로 학습 70% / 검증 15% / 테스트 15% (테스트 135일: 2026-02-16 ~ 06-30)                       |
| 시연   | Streamlit 앱 (슬라이더로 날짜·기온·강수·풍속·습도 입력)                                                 |

### 테스트 구간 성능

| 모델               | RMSE       | MAE        | R²        | MAPE(%)  |
| ------------------ | ---------- | ---------- | --------- | -------- |
| 전주 동일요일      | 36,732     | 24,151     | -0.109    | 39.8     |
| 선형회귀           | 17,006     | 13,059     | 0.762     | 17.4     |
| 랜덤포레스트       | 16,109     | 11,952     | 0.787     | 16.8     |
| **LSTM (본 모델)** | **15,832** | **11,550** | **0.794** | **13.7** |

LSTM이 가장 좋지만 랜덤포레스트와 차이는 작다(R² 0.007).

### 날씨 시나리오 분석 요약

- 강수량: 맑은 날 대비 1mm에서 약 -8%, 10mm에서 -29.9%, 30mm에서 -43.7%
- 평균기온: 올라갈수록 수요 증가 (-10℃ 약 9.5만 건 → 34℃ 약 13.6만 건), 약 30℃ 이후 완만
- 학습 데이터의 평균기온 범위는 -11.7 ~ 32.8℃ 이므로 이 범위 밖은 해석하지 않는다.

## 3. 실행 방법 (Windows 기준)

VS Code 터미널(또는 명령 프롬프트)에서 `DL_PRJ` 폴더로 이동한 뒤 진행한다.

### 3-1. 앱만 실행 (발표 시연, 백업용)

```
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

- 앱은 TensorFlow 없이 numpy로 예측한다. (노트북에서 Keras 결과와 최대 오차 약 3×10⁻⁷ 이내임을 확인)
- 같은 와이파이의 다른 기기에서 접속: `streamlit run app.py --server.address 0.0.0.0` 로 실행 후 `http://(ipconfig의 IPv4 주소):8501`

### 3-2. 노트북 처음부터 다시 실행 (학습 포함)

```
.venv\Scripts\activate
pip install -r requirements_notebook.txt
```

설치 후 VS Code에서 `ddareungi_project.ipynb`를 열고 **커널을 다시 시작**한 뒤 위에서부터 순서대로 실행한다.

- 첫 셀에 현재 위치와 찾은 데이터 폴더가 출력된다. `data/bike`를 못 찾으면 원인 안내가 나온다.
- 실행이 끝나면 `model_weights.npz`, `meta.json`, `daily_dataset.csv`, `test_pred.csv`, `figs/`가 새로 만들어진다.
- 시드를 42로 고정했지만 라이브러리 버전이 다르면 소수점 아래 수치가 조금 달라질 수 있다.
- 그래프 한글은 나눔고딕 → 맑은 고딕 순으로 사용한다.

## 4. Streamlit Cloud 배포

1. 이 `DL_PRJ` 폴더를 GitHub 저장소(Public)로 올린다. `.gitignore`가 `.venv`(수백 MB)를 제외한다.
   ```
   git init
   git add .
   git status        ← .venv 가 목록에 없는지 확인
   git commit -m "따릉이 수요 예측"
   ```
   이후 GitHub에서 새 저장소를 만들고 안내되는 `git remote add` / `git push` 명령을 실행한다.
2. https://share.streamlit.io 에 GitHub 계정으로 로그인 → Create app → 저장소 선택, Main file path = `app.py` → Deploy
3. 발급된 주소를 이 README 위쪽과 보고서에 적어 둔다.
4. 발표 전날 접속해 앱이 정상인지 확인한다. 오래 사용하지 않으면 앱이 잠들어 첫 접속이 느릴 수 있다.
5. 만일에 대비해 3-1 로컬 실행도 한 번 테스트해 둔다.

## 5. 앱 사용법

- 사이드바에서 **예측 대상일**을 고른다. 범위는 2024-01-15 ~ 2026-07-01(데이터 마지막 날의 다음 날)이다.
- 평균기온·일강수량·평균풍속·평균습도 슬라이더를 움직이면 "원래 날씨 대비" 예측 대여건수와 변화율(%)이 바뀐다. 슬라이더 기본값은 그날의 실제 날씨다.
- 탭: 시나리오 시뮬레이터 / 기온·강수 민감도 / 모델 성능 / 데이터
- 공휴일과 주말은 자동으로 반영된다. (예: 2025-08-15 광복절)

## 7. 문제 해결

| 증상                                                | 원인과 해결                                                                                                         |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `ModuleNotFoundError: No module named 'tensorflow'` | 가상환경에 TensorFlow가 없는 것. `pip install -r requirements_notebook.txt` 후 커널 재시작. (앱 실행에는 필요 없음) |
| `ModuleNotFoundError: No module named 'sklearn'`    | 위와 같은 명령으로 scikit-learn 설치                                                                                |
| `NameError: name 'model' is not defined`            | 앞 셀(모델 정의)이 실패한 연쇄 오류. 첫 오류부터 해결하고 위에서부터 다시 실행                                      |
| 그래프 한글이 네모로 깨짐                           | 나눔고딕 또는 맑은 고딕이 있는지 확인 후 커널 재시작                                                                |
| 앱에서 `FileNotFoundError: meta.json`               | 모델·데이터 4개 파일이 `app.py`와 같은 위치에 있어야 함                                                             |
| Streamlit Cloud 배포 후 `ModuleNotFoundError`       | `requirements.txt`가 저장소 최상위에 있는지 확인                                                                    |

## 8. 한계

- 데이터가 약 2년 반(912일)이라 여름을 두 번만 학습했다.
- 일 강수량 합계만 사용해 비가 온 시간대를 알 수 없다.
- 학습·평가에 예보가 아닌 **실측 기상**을 입력으로 썼다. 실제로 쓰려면 기상예보를 넣어야 하고 예보 오차가 더해진다.
- 학습 손실과 검증 손실 사이에 간격이 있어 약한 과적합 경향이 있다. (조기 종료로 완화)
- 시나리오 분석은 모델이 학습한 상관관계에 기반한 추정이며, 인과 효과를 보장하지 않는다.
